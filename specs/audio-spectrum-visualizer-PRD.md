# 오디오 스펙트럼 비주얼라이저 PRD (Product Requirements Document)

## 1. 개요

### 1.1 제품 비전

- **목적**: 누구나 쉽게 음악 비주얼라이저 영상을 제작할 수 있는 웹 서비스 제공
- **핵심 가치 제안**: 전문 지식이나 영상 편집 소프트웨어 없이 MP3 파일만으로 고품질 스펙트럼 시각화 영상(MP4) 생성
- **성공 지표 (KPIs)**:
  - 월간 활성 사용자 수 (MAU)
  - 영상 생성 완료율 (업로드 → 다운로드 전환율)
  - 평균 제작 소요 시간
  - 재방문율

### 1.2 배경

- **현재 문제점**:
  - 음악 비주얼라이저 영상 제작을 위해 After Effects, Premiere 등 전문 도구 필요
  - 학습 곡선이 높고 비용 부담
  - 기존 온라인 도구는 기능 제한적이거나 서버 의존적

- **기회**:
  - 유튜브, 인스타그램 등 음악 콘텐츠 수요 증가
  - 브라우저 기술 발전으로 클라이언트 사이드 렌더링 가능
  - 서버 비용 없이 확장 가능한 서비스 모델

- **경쟁 분석**:
  | 경쟁사 | 장점 | 단점 |
  |--------|------|------|
  | Renderforest | 다양한 템플릿 | 유료, 워터마크 |
  | VEED | 간편한 UI | 기능 제한적 |
  | After Effects | 전문적 품질 | 높은 진입장벽, 고가 |

## 2. 사용자 정의

### 2.1 타겟 사용자

| 페르소나 | 설명 | 주요 니즈 |
|----------|------|-----------|
| 인디 뮤지션 | 자작곡 홍보 영상이 필요한 음악가 | 빠르고 저렴하게 프로모션 영상 제작 |
| 유튜브 크리에이터 | 음악 관련 콘텐츠 제작자 | 시각적으로 매력적인 배경 영상 |
| SNS 사용자 | 좋아하는 음악을 공유하고 싶은 일반인 | 가사와 함께 감성적인 영상 제작 |
| 팟캐스트 운영자 | 오디오 콘텐츠를 영상으로 변환 필요 | 음성에 맞는 시각 효과 |

### 2.2 사용자 스토리

- As a **인디 뮤지션**, I want to **내 음악에 맞는 시각화 영상을 쉽게 만들고 싶어요**, so that **유튜브/인스타그램에 프로모션할 수 있어요**
- As a **일반 사용자**, I want to **좋아하는 노래에 가사를 넣은 영상을 만들고 싶어요**, so that **SNS에 공유할 수 있어요**
- As a **크리에이터**, I want to **다양한 스펙트럼 스타일을 선택하고 커스터마이징하고 싶어요**, so that **내 채널 정체성에 맞는 영상을 만들 수 있어요**

### 2.3 사용자 여정

```
인지 → 접속 → 제작 → 다운로드 → 공유
```

**상세 흐름:**
1. 서비스 발견 (검색/SNS)
2. 메인 페이지 접속
3. (동시 접속 초과 시) 대기열 진입
4. MP3 파일 업로드
5. (선택) 원본 가사 업로드
6. Whisper API → 타임스탬프 + 가사 자동 추출
7. (원본 가사 있으면) 자동 매칭 결과 확인
8. 배경 이미지 선택
9. 스펙트럼 스타일 선택 및 커스터마이징
10. 타임라인에서 가사 편집 (원본 가사 패널 참조)
11. 자막 스타일 설정
12. 실시간 미리보기 확인
13. 렌더링 진행
14. MP4 다운로드 (+ SRT 다운로드 옵션)
15. SNS 공유

## 3. 기능 요구사항

### 3.1 P0 (Must-have) - MVP

| ID | 기능 | 설명 | 성공 기준 |
|----|------|------|-----------|
| F001 | MP3 업로드 | 사용자 음악 파일 업로드 | 일반적인 MP3 파일 인식 및 재생 가능 |
| F002 | 배경 이미지 업로드 | 영상 배경으로 사용할 이미지 설정 | JPG/PNG 지원, 미리보기 표시 |
| F003 | 스펙트럼 프리셋 | Bar, Waveform, Circular 등 기본 스타일 | 최소 4종 프리셋 제공 |
| F004 | 스펙트럼 커스터마이징 | 색상, 크기 조절 | 실시간 미리보기에 반영 |
| F005 | Whisper 자동 자막 생성 | MP3에서 자동으로 타임스탬프 + 가사 추출 | Whisper API 연동, 정확도 80% 이상 |
| F006 | 원본 가사 업로드 (선택) | Whisper 인식 오류 보정용 원본 가사 | 텍스트 파일 업로드, 매칭 UI 제공 |
| F007 | Whisper + 원본 가사 매칭 | 정규화/유사도 기반 자동 매칭 | 매칭 성공/실패 표시, 사용자 확인 UI |
| F008 | 원본 가사 패널 | 원본 가사 표시 및 복사 기능 | 클릭으로 복사, 사용 여부 표시 |
| F009 | 타임라인 가사 편집 | 가사 텍스트/타이밍/순서 수정 | 드래그로 조절, 즉시 반영 |
| F010 | 자막 스타일 시스템 | 전체 기본값 + 개별 오버라이드 | 가사별 다른 위치/색상/크기 적용 |
| F011 | 실시간 미리보기 | 편집 결과 즉시 확인 | 설정 변경 시 1초 내 반영 |
| F012 | MP4 렌더링 | 브라우저에서 영상 생성 | 음악 전체 길이 영상 완성 |
| F013 | SRT 다운로드 | 편집된 가사를 SRT 파일로 내보내기 | 표준 SRT 포맷 출력 |
| F014 | 대기열 시스템 | 동시 접속 20명 초과 시 대기 | 대기 순서 표시, 순차 입장 |

### 3.2 P1 (Should-have) - Phase 2

| ID | 기능 | 설명 | 성공 기준 |
|----|------|------|-----------|
| F101 | 파라미터 상세 조절 | 막대 개수, 감도, 애니메이션 속도 | 세부 수치 조절 UI |
| F102 | 해상도 선택 | 720p / 1080p / 4K | 렌더링 옵션에서 선택 가능 |
| F103 | 커스텀 스펙트럼 | 사용자 정의 모양/동작 | 에디터 UI 제공 |

### 3.3 P2 (Nice-to-have) - Future

| ID | 기능 | 설명 |
|----|------|------|
| F201 | 템플릿 저장/공유 | 설정을 저장하고 재사용 |
| F202 | 계정 시스템 | 작업 히스토리, 클라우드 저장 |
| F203 | 다국어 Whisper 모델 최적화 | 한국어/영어 외 언어 정확도 향상 |

### 3.4 Out of Scope

- 서버 사이드 렌더링 (클라이언트 전용)
- 실시간 스트리밍 기능
- 영상 호스팅 서비스
- 다중 트랙 믹싱
- MP3 외 오디오 포맷 지원 (WAV, FLAC 등)

## 4. 비기능 요구사항

### 4.1 성능

- **응답 시간**: 미리보기 반영 1초 이내
- **동시 사용자**: 최대 20명 (초과 시 대기열)
- **렌더링**: 사용자 PC 자원 활용, 음악 전체 길이 지원

### 4.2 보안/규정

- **인증 요구사항**: MVP에서 불필요 (익명 사용)
- **데이터 보호**: 업로드 파일은 브라우저 로컬에서만 처리
- **규제 준수**: 저작권 책임은 사용자에게 고지

### 4.3 접근성

- **지원 디바이스**: 데스크톱 (모바일 미지원)
- **브라우저 호환성**: Chrome, Firefox, Safari, Edge (최신 버전)
- **최소 사양**: Web Audio API, Canvas API 지원 브라우저

## 5. 제약조건

### 5.1 일정

- **목표 출시일**: (협의 필요)
- **마일스톤**:
  - M1: 핵심 기능 (업로드, 스펙트럼, 렌더링)
  - M2: Whisper API 연동 및 자동 자막 생성
  - M3: 원본 가사 매칭 및 가사 편집 시스템
  - M4: 대기열 및 최적화
  - M5: QA 및 출시

### 5.2 예산

- **개발 예산**: (협의 필요)
- **운영 예산**:
  - Self-hosting (Fly.io, Render, Railway 등)
  - Whisper API 비용: 약 $0.006/분 (5분 음악 ≈ $0.03)

### 5.3 의존성

- **외부 시스템**:
  - Self-hosting 플랫폼 (Fly.io, Render, Railway 등)
  - OpenAI Whisper API
- **팀 리소스**: 프론트엔드 개발자, 백엔드 개발자 (Python FastAPI)

## 6. 리스크 및 가정

### 6.1 주요 리스크

| 리스크 | 영향도 | 대응 방안 |
|--------|--------|-----------|
| 브라우저 렌더링 성능 한계 | 높음 | 최적화, 해상도 제한, 진행률 표시 |
| 클라이언트 메모리 부족 | 중간 | 긴 음악 파일 경고, 청크 처리 |
| 브라우저 호환성 이슈 | 중간 | 지원 브라우저 명시, 폴백 제공 |
| Whisper API 인식 오류 | 중간 | 원본 가사 매칭, 사용자 수정 UI 제공 |
| Whisper API 비용 증가 | 낮음 | 사용량 모니터링, 캐싱 적용 |
| 저작권 분쟁 | 낮음 | 사용자 책임 고지, 이용약관 |

### 6.2 가정사항

- 사용자 PC는 최소 4GB RAM, 최신 브라우저 사용
- 업로드 파일은 합법적으로 소유한 음악
- 동시 접속 20명 이상 트래픽은 초기에 발생하지 않음
- 클라이언트 사이드 렌더링으로 서버 비용 최소화 가능
