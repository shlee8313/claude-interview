# 오디오 스펙트럼 비주얼라이저 PRD (Product Requirements Document)

## 1. 개요

### 1.1 제품 비전
- **목적**: 사용자가 MP3 파일을 업로드하면 음악에 맞는 스펙트럼 시각화 영상(MP4)을 생성
- **핵심 가치 제안**: 전문 지식 없이도 쉽게 음악 비주얼라이저 영상 제작
- **성공 지표 (KPIs)**:
  - 영상 생성 완료율 (목표: 90% 이상)
  - 평균 영상 생성 시간
  - 동시 접속자 처리 안정성

### 1.2 배경
- **현재 문제점**: 음악 비주얼라이저 영상 제작에는 전문 영상 편집 소프트웨어나 기술적 지식이 필요
- **기회**: 웹 브라우저만으로 누구나 쉽게 음악 영상 제작 가능
- **경쟁 분석**: 기존 도구들은 데스크톱 설치 필요 또는 고가의 구독료 요구

## 2. 사용자 정의

### 2.1 타겟 사용자
| 페르소나 | 설명 | 주요 니즈 |
|----------|------|-----------|
| 음악 크리에이터 | 자작곡을 SNS에 공유하고 싶은 사용자 | 빠르고 쉬운 영상 생성 |
| 유튜브 업로더 | 음악 채널을 운영하는 콘텐츠 제작자 | 가사 포함 영상, 다양한 스타일 |
| 일반 사용자 | 좋아하는 음악으로 영상을 만들고 싶은 누구나 | 직관적인 UI, 무료 사용 |

### 2.2 사용자 스토리
- As a 음악 크리에이터, I want to 내 음악에 맞는 비주얼라이저 영상을 만들고 싶어, so that SNS에 공유할 수 있다
- As a 유튜브 업로더, I want to 가사가 포함된 음악 영상을 만들고 싶어, so that 시청자가 가사를 보며 음악을 들을 수 있다
- As a 일반 사용자, I want to 복잡한 설정 없이 빠르게 영상을 만들고 싶어, so that 시간을 절약할 수 있다

### 2.3 사용자 여정
```
1. 메인 페이지 접속
   ↓
2. 동시 접속 20명 초과 시 → 대기열 화면
   ↓
3. MP3 파일 업로드
   ↓
4. 배경 이미지 업로드
   ↓
5. 스펙트럼 스타일 선택 및 커스터마이징
   ↓
6. (선택) SRT 자막 업로드
   ↓
7. (선택) 타임라인에서 가사 편집
   ↓
8. 자막 스타일 설정
   ↓
9. 미리보기 확인
   ↓
10. 렌더링 시작 → 진행률 표시
    ↓
11. MP4 다운로드
```

## 3. 기능 요구사항

### 3.1 P0 (Must-have) - MVP
| ID | 기능 | 설명 | 성공 기준 |
|----|------|------|-----------|
| F001 | MP3 업로드 | 사용자가 음악 파일 업로드 | MP3 파일 정상 로드 및 재생 가능 |
| F002 | 배경 이미지 업로드 | 영상 배경으로 사용할 이미지 업로드 | 이미지 미리보기 정상 표시 |
| F003 | 스펙트럼 프리셋 | Bar, Waveform, Circular 등 기본 스타일 제공 | 4개 이상 프리셋 선택 가능 |
| F004 | 스펙트럼 스타일 조절 | 색상, 크기 커스터마이징 | 변경 사항 실시간 미리보기 반영 |
| F005 | SRT 자막 업로드 | 싱크 가사 파일 업로드 (선택사항) | SRT 파싱 및 타임라인 표시 |
| F006 | 타임라인 가사 편집 | 가사 텍스트/타이밍 수정, 추가/삭제, 순서 변경 | 드래그 앤 드롭 정상 동작 |
| F007 | 자막 스타일 시스템 | 전체 기본 스타일 + 개별 가사 오버라이드 | 가사별 다른 스타일 적용 가능 |
| F008 | MP4 렌더링 | 브라우저에서 영상 렌더링 후 다운로드 | 음악 전체 길이 영상 생성 완료 |
| F009 | 대기열 시스템 | 동시 접속 20명 초과 시 대기열 처리 | 대기 순서 표시 및 자동 입장 |
| F010 | 실시간 미리보기 | 편집 내용 실시간 확인 | 설정 변경 시 0.5초 내 반영 |

### 3.2 P1 (Should-have) - Phase 2
| ID | 기능 | 설명 | 성공 기준 |
|----|------|------|-----------|
| F101 | 파라미터 상세 조절 | 막대 개수, 감도, 애니메이션 속도 등 | 각 파라미터 슬라이더로 조절 가능 |
| F102 | 해상도 선택 | 720p / 1080p / 4K 선택 | 선택한 해상도로 렌더링 완료 |

### 3.3 P2 (Nice-to-have) - Future
| ID | 기능 | 설명 |
|----|------|------|
| F201 | 완전한 커스텀 스펙트럼 | 사용자가 직접 스펙트럼 모양/동작 정의 |
| F202 | 템플릿 저장/불러오기 | 자주 사용하는 설정 저장 |
| F203 | 영상 프리뷰 공유 | 렌더링 전 미리보기 링크 공유 |

### 3.4 Out of Scope
- 서버 사이드 렌더링 (클라이언트 전용)
- MP3 외 다른 오디오 포맷 지원 (MVP에서 제외)
- 자동 가사 생성/AI 음성 인식 (외부 AI 서버 불필요)
- 사용자 계정/로그인 시스템
- 영상 클라우드 저장

## 4. 비기능 요구사항

### 4.1 성능
- **응답 시간**: 미리보기 반영 0.5초 이내
- **동시 사용자**: 최대 20명 (초과 시 대기열)
- **렌더링**: 사용자 PC 자원 활용, 음악 전체 길이 지원

### 4.2 보안/규정
- **인증 요구사항**: 없음 (비로그인 서비스)
- **데이터 보호**: 업로드 파일 서버 미저장, 브라우저 로컬 처리
- **규제 준수**: 해당 없음

### 4.3 접근성
- **지원 디바이스**: 데스크톱 웹 브라우저 (모바일은 Phase 2 고려)
- **브라우저 호환성**: Chrome, Firefox, Edge 최신 버전

## 5. 제약조건

### 5.1 기술적 제약
- Vercel 서버리스 환경 (외부 서버 없음)
- 클라이언트 사이드 렌더링 전용
- 입력: MP3 / 출력: MP4

### 5.2 예산
- **개발 예산**: 서버 비용 최소화 (Vercel 무료/저가 플랜)
- **운영 예산**: 월간 고정 비용 없음 목표

### 5.3 의존성
- Web Audio API (브라우저 내장)
- Canvas API (브라우저 내장)
- MediaRecorder API 또는 ffmpeg.wasm

## 6. 리스크 및 가정

### 6.1 주요 리스크
| 리스크 | 영향도 | 대응 방안 |
|--------|--------|-----------|
| 브라우저 렌더링 성능 한계 | 높음 | 해상도 제한, 진행률 표시로 UX 개선 |
| 동시 접속 폭주 | 중간 | 대기열 시스템으로 안정성 확보 |
| 긴 음악 파일 처리 지연 | 중간 | 청크 단위 처리, 진행 상황 표시 |

### 6.2 가정사항
- 사용자는 최신 브라우저를 사용한다
- 사용자 PC가 영상 렌더링을 처리할 수 있는 성능을 갖추고 있다
- SRT 파일 형식은 표준 형식을 따른다
