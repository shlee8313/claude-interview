# 오디오 스펙트럼 비주얼라이저 사양서

## 1. 개요

- **목적**: 사용자가 MP3 파일을 업로드하면 음악에 맞는 스펙트럼 시각화 영상(MP4)을 생성
- **타겟 사용자**: 일반 사용자 (음악 영상 제작이 필요한 누구나)
- **핵심 가치**: 전문 지식 없이도 쉽게 음악 비주얼라이저 영상 제작

## 2. 기능 요구사항

### 2.1 필수 기능 (MVP)

- [ ] **MP3 업로드**: 사용자가 음악 파일 업로드
- [ ] **배경 이미지 업로드**: 영상 배경으로 사용할 이미지 업로드
- [ ] **스펙트럼 시각화**: 여러 프리셋 중 선택
  - Bar (막대형)
  - Waveform (파형)
  - Circular (원형)
  - 기타 기본 스타일
- [ ] **스펙트럼 스타일 조절**: 색상, 크기 커스터마이징
- [ ] **SRT 자막 업로드**: 싱크 가사 파일 업로드 (선택사항)
- [ ] **타임라인 가사 편집**: (상세 내용 섹션 7.2 참조)
  - 가사 텍스트 수정
  - 타이밍(시작/끝) 조절 - 드래그로 늘이기/줄이기
  - 가사 추가/삭제
  - 가사 순서 변경 - 드래그로 위치 이동
- [ ] **자막 스타일 시스템**:
  - 전체 기본 스타일 설정 (폰트, 크기, 색상, 위치)
  - 개별 가사 오버라이드 (가사마다 다른 스타일 적용 가능)
- [ ] **MP4 렌더링**: 브라우저에서 영상 렌더링 후 다운로드
- [ ] **대기열 시스템**: 동시 접속 20명 초과 시 대기열 처리

### 2.2 추가 기능 (Phase 2)

- [ ] **파라미터 상세 조절**: 막대 개수, 감도, 애니메이션 속도 등
- [ ] **완전한 커스텀 스펙트럼**: 사용자가 직접 스펙트럼 모양/동작 정의
- [ ] **해상도 선택**: 720p / 1080p / 4K

## 3. 기술 스택

- **Frontend**: React + TypeScript + Tailwind CSS
- **오디오 분석**: Web Audio API
- **영상 렌더링**: Canvas API + MediaRecorder API (또는 ffmpeg.wasm)
- **배포**: Vercel
- **상태 관리**: Zustand 또는 React Context

## 4. 비기능 요구사항

### 4.1 성능
- 브라우저에서 렌더링 (사용자 PC 자원 활용)
- 음악 전체 길이 영상 생성 지원

### 4.2 동시성
- 최대 동시 접속자: 20명
- 초과 시 대기열 표시 및 순서 대기

### 4.3 사용성
- 직관적인 UI/UX
- 실시간 미리보기 제공

## 5. 제약조건

- **서버**: Vercel 서버리스 (외부 서버 없음)
- **렌더링**: 클라이언트 사이드 전용
- **파일 형식**: 입력 MP3, 출력 MP4

## 6. 사용자 플로우

```
1. 메인 페이지 접속
   ↓
2. 동시 접속 20명 초과 시 → 대기열 화면
   ↓
3. MP3 파일 업로드
   ↓
4. 배경 이미지 업로드
   ↓
5. 스펙트럼 스타일 선택 및 커스터마이징
   ↓
6. (선택) SRT 자막 업로드
   ↓
7. (선택) 타임라인에서 가사 편집
   ↓
8. 자막 스타일 설정
   ↓
9. 미리보기 확인
   ↓
10. 렌더링 시작 → 진행률 표시
    ↓
11. MP4 다운로드
```

### 7.2 타임라인 가사 편집 상세

#### 타임라인 기본 뷰

```
|[가사1][+][가사2][+][가사3][+][가사4][+]|
        ↑ 각 박스 끝 상단에 작은 + 버튼
```

#### 인터랙션 정의

| 동작 | 방법 |
|------|------|
| 가사 수정 | 박스 클릭 → 확대 모드 → 텍스트/타이밍/스타일 수정 |
| 저장 | Enter 키 |
| 취소 | ESC 키 또는 바깥 영역 클릭 |
| 가사 추가 | [+] 버튼 클릭 → 빈 박스 생성 → 입력 → Enter |
| 가사 삭제 | 확대 모드 → 삭제 버튼 클릭 |
| 타이밍 조절 | 박스 양 끝 드래그로 늘이기/줄이기 |
| 순서 변경 | 박스 드래그로 위치 이동 |

#### 확대 모드 (가사 편집 팝업)

```
┌─ 가사 편집 ─────────────────────────┐
│  가사: [______________________]     │
│  시작: [00:15]  끝: [00:18]         │
│  ───────────────────────────────    │
│  위치: [☑ 개별설정] [상단 ▼]        │
│  색상: [☐ 기본값 사용]              │
│  크기: [☑ 개별설정] [크게 ▼]        │
│                                     │
│                          [삭제]     │
└─────────────────────────────────────┘
Enter = 저장 후 닫기
ESC / 바깥 클릭 = 취소 후 닫기
```

#### 자막 스타일 시스템

**1. 전체 기본 스타일 설정 (설정 패널)**
```
┌─ 자막 기본 설정 ─────────────────┐
│  기본 위치: [하단 ▼]             │
│  기본 색상: [■ 흰색]             │
│  기본 크기: [중간 ▼]             │
│  기본 폰트: [Pretendard ▼]       │
└─────────────────────────────────┘
```

**2. 개별 가사 오버라이드**
- 확대 모드에서 "개별설정" 체크 시 해당 가사만 다른 스타일 적용
- 체크 해제 시 전체 기본 스타일 따름

**3. 가사별 위치 예시**
```
┌─────────────────────────┐
│    "가사3 - 상단"       │  ← 00:20~00:25 (개별설정: 상단)
│                         │
│    "가사2 - 중간"       │  ← 00:10~00:15 (개별설정: 중간)
│                         │
│    "가사1 - 하단"       │  ← 00:00~00:05 (기본값: 하단)
└─────────────────────────┘
```

## 8. 결정 사항 요약

| 항목 | 결정 | 근거 |
|------|------|------|
| 플랫폼 | 웹 앱 | 다수 사용자 접근성 |
| 렌더링 위치 | 브라우저 | 서버 비용 절감, Vercel 제한 회피 |
| 자막 입력 | SRT 업로드 | 외부 AI 서버 불필요, 단순화 |
| 가사 편집 | 타임라인 UI + 확대 모드 | SRT 오류 수정, 직관적 편집 |
| 가사 스타일 | 기본값 + 개별 오버라이드 | 유연성, 가사별 다른 위치/스타일 지원 |
| 동시 접속 | 20명 제한 + 대기열 | 서비스 안정성 |
| 기본 해상도 | 1080p (MVP) | 범용성, Phase 2에서 선택 추가 |
