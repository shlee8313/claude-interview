# 오디오 스펙트럼 비주얼라이저 사양서

## 1. 개요

- **목적**: 사용자가 MP3 파일을 업로드하면 음악에 맞는 스펙트럼 시각화 영상(MP4)을 생성
- **타겟 사용자**: 일반 사용자 (음악 영상 제작이 필요한 누구나)
- **핵심 가치**: 전문 지식 없이도 쉽게 음악 비주얼라이저 영상 제작

## 2. 기능 요구사항

### 2.1 필수 기능 (MVP)

- [ ] **MP3 업로드**: 사용자가 음악 파일 업로드
- [ ] **배경 이미지 업로드**: 영상 배경으로 사용할 이미지 업로드
- [ ] **스펙트럼 시각화**: 여러 프리셋 중 선택
  - Bar (막대형)
  - Waveform (파형)
  - Circular (원형)
  - 기타 기본 스타일
- [ ] **스펙트럼 스타일 조절**: 색상, 크기 커스터마이징
- [ ] **SRT 자막 업로드**: 싱크 가사 파일 업로드 (선택사항)
- [ ] **타임라인 가사 편집**:
  - 가사 텍스트 수정
  - 타이밍(시작/끝) 조절
  - 가사 추가/삭제
- [ ] **자막 스타일 커스텀**: 폰트, 크기, 색상, 위치 조절
- [ ] **MP4 렌더링**: 브라우저에서 영상 렌더링 후 다운로드
- [ ] **대기열 시스템**: 동시 접속 20명 초과 시 대기열 처리

### 2.2 추가 기능 (Phase 2)

- [ ] **파라미터 상세 조절**: 막대 개수, 감도, 애니메이션 속도 등
- [ ] **완전한 커스텀 스펙트럼**: 사용자가 직접 스펙트럼 모양/동작 정의
- [ ] **해상도 선택**: 720p / 1080p / 4K

## 3. 기술 스택

- **Frontend**: React + TypeScript + Tailwind CSS
- **오디오 분석**: Web Audio API
- **영상 렌더링**: Canvas API + MediaRecorder API (또는 ffmpeg.wasm)
- **배포**: Vercel
- **상태 관리**: Zustand 또는 React Context

## 4. 비기능 요구사항

### 4.1 성능
- 브라우저에서 렌더링 (사용자 PC 자원 활용)
- 음악 전체 길이 영상 생성 지원

### 4.2 동시성
- 최대 동시 접속자: 20명
- 초과 시 대기열 표시 및 순서 대기

### 4.3 사용성
- 직관적인 UI/UX
- 실시간 미리보기 제공

## 5. 제약조건

- **서버**: Vercel 서버리스 (외부 서버 없음)
- **렌더링**: 클라이언트 사이드 전용
- **파일 형식**: 입력 MP3, 출력 MP4

## 6. 사용자 플로우

```
1. 메인 페이지 접속
   ↓
2. 동시 접속 20명 초과 시 → 대기열 화면
   ↓
3. MP3 파일 업로드
   ↓
4. 배경 이미지 업로드
   ↓
5. 스펙트럼 스타일 선택 및 커스터마이징
   ↓
6. (선택) SRT 자막 업로드
   ↓
7. (선택) 타임라인에서 가사 편집
   ↓
8. 자막 스타일 설정
   ↓
9. 미리보기 확인
   ↓
10. 렌더링 시작 → 진행률 표시
    ↓
11. MP4 다운로드
```
