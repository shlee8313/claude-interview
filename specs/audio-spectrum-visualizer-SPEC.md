# 오디오 스펙트럼 비주얼라이저 사양서

## 1. 개요

- **목적**: 사용자가 MP3 파일을 업로드하면 음악에 맞는 스펙트럼 시각화 영상(MP4)을 생성
- **타겟 사용자**: 일반 사용자 (음악 영상 제작이 필요한 누구나)
- **핵심 가치**: 전문 지식 없이도 쉽게 음악 비주얼라이저 영상 제작

## 2. 기능 요구사항

### 2.1 필수 기능 (MVP)

- [ ] **MP3 업로드**: 사용자가 음악 파일 업로드
- [ ] **배경 이미지 업로드**: 영상 배경으로 사용할 이미지 업로드
- [ ] **스펙트럼 시각화**: 여러 프리셋 중 선택
  - Bar (막대형)
  - Waveform (파형)
  - Circular (원형)
  - 기타 기본 스타일
- [ ] **스펙트럼 스타일 조절**: 색상, 크기 커스터마이징
- [ ] **Whisper 자동 자막 생성**: MP3에서 자동으로 타임스탬프 + 가사 추출
- [ ] **원본 가사 업로드** (선택사항): Whisper 인식 오류 보정용
- [ ] **Whisper + 원본 가사 매칭**: (상세 내용 섹션 7.3 참조)
- [ ] **타임라인 가사 편집**: (상세 내용 섹션 7.2 참조)
  - 가사 텍스트 수정
  - 타이밍(시작/끝) 조절 - 드래그로 늘이기/줄이기
  - 가사 추가/삭제
  - 가사 순서 변경 - 드래그로 위치 이동
- [ ] **원본 가사 패널**: (상세 내용 섹션 7.4 참조)
  - 원본 가사 표시
  - 클릭으로 복사 → 타임라인에 붙여넣기
- [ ] **자막 스타일 시스템**:
  - 전체 기본 스타일 설정 (폰트, 크기, 색상, 위치)
  - 개별 가사 오버라이드 (가사마다 다른 스타일 적용 가능)
- [ ] **MP4 렌더링**: 브라우저에서 영상 렌더링 후 다운로드
- [ ] **SRT 다운로드**: 편집된 가사를 SRT 파일로 내보내기
- [ ] **대기열 시스템**: 동시 접속 20명 초과 시 대기열 처리

### 2.2 추가 기능 (Phase 2)

- [ ] **파라미터 상세 조절**: 막대 개수, 감도, 애니메이션 속도 등
- [ ] **완전한 커스텀 스펙트럼**: 사용자가 직접 스펙트럼 모양/동작 정의
- [ ] **해상도 선택**: 720p / 1080p / 4K

## 3. 기술 스택

- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: Python FastAPI
- **음성 인식**: OpenAI Whisper API
- **오디오 분석**: Web Audio API
- **영상 렌더링**: Canvas API + MediaRecorder API (또는 ffmpeg.wasm)
- **배포**: Self-hosting (Fly.io, Render, Railway 등)
- **상태 관리**: Zustand 또는 React Context

## 4. 비기능 요구사항

### 4.1 성능
- 브라우저에서 렌더링 (사용자 PC 자원 활용)
- 음악 전체 길이 영상 생성 지원

### 4.2 동시성
- 최대 동시 접속자: 20명
- 초과 시 대기열 표시 및 순서 대기

### 4.3 사용성
- 직관적인 UI/UX
- 실시간 미리보기 제공

## 5. 제약조건

- **서버**: Self-hosting (Python FastAPI)
- **렌더링**: 클라이언트 사이드 전용
- **파일 형식**: 입력 MP3, 출력 MP4
- **Whisper API 비용**: 약 $0.006/분 (5분 음악 ≈ $0.03)

## 6. 사용자 플로우

```
1. 메인 페이지 접속
   ↓
2. 동시 접속 20명 초과 시 → 대기열 화면
   ↓
3. MP3 파일 업로드
   ↓
4. (선택) 원본 가사 업로드
   ↓
5. Whisper API → 타임스탬프 + 가사 자동 추출
   ↓
6. 원본 가사 있으면 → 자동 매칭 (매칭 결과 확인)
   ↓
7. 배경 이미지 업로드
   ↓
8. 스펙트럼 스타일 선택 및 커스터마이징
   ↓
9. 타임라인에서 가사 편집 (원본 가사 패널 참조하며 수정)
   ↓
10. 자막 스타일 설정
    ↓
11. 미리보기 확인
    ↓
12. 렌더링 시작 → 진행률 표시
    ↓
13. MP4 다운로드 (+ SRT 다운로드 옵션)
```

### 7.2 타임라인 가사 편집 상세

#### 타임라인 기본 뷰

```
|[가사1][+][가사2][+][가사3][+][가사4][+]|
        ↑ 각 박스 끝 상단에 작은 + 버튼

⚠️ 표시: 자동 매칭 실패한 항목 (사용자 확인 필요)
```

#### 인터랙션 정의

| 동작 | 방법 |
|------|------|
| 가사 수정 | 박스 클릭 → 확대 모드 → 텍스트/타이밍/스타일 수정 |
| 저장 | Enter 키 |
| 취소 | ESC 키 또는 바깥 영역 클릭 |
| 가사 추가 | [+] 버튼 클릭 → 빈 박스 생성 → 입력 → Enter |
| 가사 삭제 | 확대 모드 → 삭제 버튼 클릭 |
| 타이밍 조절 | 박스 양 끝 드래그로 늘이기/줄이기 |
| 순서 변경 | 박스 드래그로 위치 이동 |
| 붙여넣기 | 원본 가사 패널에서 복사 → Ctrl+V |

#### 확대 모드 (가사 편집 팝업)

```
┌─ 가사 편집 ─────────────────────────┐
│  가사: [______________________]     │
│  시작: [00:15]  끝: [00:18]         │
│  ───────────────────────────────    │
│  위치: [☑ 개별설정] [상단 ▼]        │
│  색상: [☐ 기본값 사용]              │
│  크기: [☑ 개별설정] [크게 ▼]        │
│                                     │
│                          [삭제]     │
└─────────────────────────────────────┘
Enter = 저장 후 닫기
ESC / 바깥 클릭 = 취소 후 닫기
```

#### 자막 스타일 시스템

**1. 전체 기본 스타일 설정 (설정 패널)**
```
┌─ 자막 기본 설정 ─────────────────┐
│  기본 위치: [하단 ▼]             │
│  기본 색상: [■ 흰색]             │
│  기본 크기: [중간 ▼]             │
│  기본 폰트: [Pretendard ▼]       │
└─────────────────────────────────┘
```

**2. 개별 가사 오버라이드**
- 확대 모드에서 "개별설정" 체크 시 해당 가사만 다른 스타일 적용
- 체크 해제 시 전체 기본 스타일 따름

**3. 가사별 위치 예시**
```
┌─────────────────────────┐
│    "가사3 - 상단"       │  ← 00:20~00:25 (개별설정: 상단)
│                         │
│    "가사2 - 중간"       │  ← 00:10~00:15 (개별설정: 중간)
│                         │
│    "가사1 - 하단"       │  ← 00:00~00:05 (기본값: 하단)
└─────────────────────────┘
```

### 7.3 Whisper + 원본 가사 매칭 로직

#### 처리 흐름

```
┌─────────────────────────────────────────┐
│ 입력                                    │
│ ├── MP3 파일                            │
│ └── 원본 가사 (선택)                    │
└─────────────────────────────────────────┘
                ↓
┌─────────────────────────────────────────┐
│ Whisper API                             │
│ └── 결과: 타임스탬프 + 인식된 텍스트    │
└─────────────────────────────────────────┘
                ↓
┌─────────────────────────────────────────┐
│ 매칭 로직 (원본 가사 있는 경우)         │
│                                         │
│ 1차: 정규화 후 정확 매칭                │
│     - 특수문자 제거 (. , ! ? ~ ♪)       │
│     - 공백 통일                         │
│     - 순서 기반 위치 포인터 사용        │
│              ↓ 실패하면                 │
│ 2차: 유사도 매칭 (70% 이상)             │
│     - 축약어 대응 (너를→널)             │
│              ↓ 실패하면                 │
│ 3차: ⚠️ 사용자 확인 표시                │
└─────────────────────────────────────────┘
                ↓
┌─────────────────────────────────────────┐
│ 결과                                    │
│ ├── ✅ 매칭됨: Whisper 타이밍 + 원본 가사│
│ └── ⚠️ 확인필요: 사용자 수정            │
└─────────────────────────────────────────┘
```

#### 매칭 방식

**전체 텍스트 매칭 (줄 단위 X)**

노래는 문장과 다르게 끊어지므로 줄 단위 매칭이 아닌 전체 텍스트에서 부분 매칭:

```
원본 (줄바꿈 제거): "너를 만나고 이렇게 좋은데 어쩌면 우린 달라"
                    ↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑↑
Whisper 세그먼트:   "만나고 이렇게 좋은데 어쩌면"
                    → 위치 3~21에서 매칭 ✅

순서 기반 위치 포인터로 중복 가사 처리:
- 이미 매칭된 위치 이후에서만 검색
- "너를"이 여러 번 나와도 순서대로 매칭
```

#### 엣지 케이스 처리

| 케이스 | 처리 방법 |
|--------|-----------|
| 특수문자 (. , ! ♪) | 정규화 시 제거 |
| 띄어쓰기 차이 | 공백 통일 |
| 축약어 (너를→널) | 유사도 매칭 |
| 영어 발음 인식 (I love → 아이 러브) | ⚠️ 사용자 확인 |
| 추임새/애드리브 | 부분 매칭 또는 ⚠️ 표시 |
| 숫자 표기 (3년→삼년) | 변환 후 비교 |
| 후렴 반복 | 순서 기반 매칭 |
| 인트로 노이즈 | 매칭 안 되면 ⚠️ 표시 |

### 7.4 원본 가사 패널

#### 용도
- Whisper 매칭이 완벽하지 않을 경우 사용자가 직접 복사하여 수정
- 원본 가사를 참조하며 타임라인 편집

#### UI

```
┌─ 📋 원본 가사 ──────────────────┐
│  [전체 복사]                    │
│  ─────────────────────────────  │
│  너를 만나고          [복사]    │  ← 클릭 시 해당 줄 복사
│  이렇게 좋은데        [복사]    │
│  ▒ 어쩌면 우린 ▒      [복사]    │  ← 이미 사용된 가사 (흐리게)
│  달라질 수 있을까     [복사]    │
│                                 │
│  [🔍 검색...]                   │  ← 긴 가사일 경우
└─────────────────────────────────┘
```

#### 인터랙션

| 동작 | 방법 |
|------|------|
| 줄 복사 | 가사 줄 클릭 또는 [복사] 버튼 |
| 여러 줄 복사 | 드래그로 선택 |
| 전체 복사 | [전체 복사] 버튼 |
| 붙여넣기 | 타임라인 박스 편집 중 Ctrl+V |
| 검색 | 검색창에 키워드 입력 |

#### 시각적 표시
- **사용됨**: 이미 타임라인에 있는 가사 → 흐리게 표시
- **미사용**: 아직 타임라인에 없는 가사 → 정상 표시
